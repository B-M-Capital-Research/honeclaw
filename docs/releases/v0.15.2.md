# v0.15.2

发布日期：2026-07-27

English readers: please scroll down for the English version below.

## 用户应该知道的

- 这是一次生产部署与 Apple 安装包刷新版本，不新增或改变既有回答格式、交互流程与业务能力。
- 生产后端将从旧的 `0.14.1` 运行版本升级到当前安全基线，包含 `v0.15.1` 已发布的公共站点安全响应头、短信登录防枚举与服务端限流、附件解压资源上限、图表渲染边界、凭据文件权限和依赖安全修复。
- macOS Universal DMG、iOS Simulator App 与 iOS Xcode 工程将从当前 `main` 重新构建，并统一标记为 `0.15.2`。
- 自 `v0.15.1` 以来只有缺陷台账证据更新，没有新的运行时代码或架构变化。

## 谁应该尽快更新

- 仍运行 `0.14.x` 后端、尚未部署 `v0.15.1` 安全修复的维护者。
- 希望获取与当前生产部署和 GitHub tag 完全对应的 macOS/iOS 构建产物的用户。

## 升级后会有什么变化

- 后端会通过既有 supervisor 在活跃会话为零时受控替换，并继续使用云端 PostgreSQL/R2 作为唯一权威存储。
- 公共 Web、Feishu、鉴权边界、会话历史和 Apple 客户端格式保持兼容。
- 本次没有改变模块边界、主要路由拓扑、Agent runner、工具、channel 或存储布局，因此 `resources/architecture.svg` 无需更新。

## 安装与更新

- macOS 用户端：从 GitHub Release 下载 `HONE-macOS-v0.15.2-universal.dmg`。
- iOS 开发/验证：下载 `HONE-iOS-Simulator-v0.15.2.zip` 或 `HONE-iOS-Xcode-v0.15.2.zip`；真机分发仍需在 Xcode 中配置 Apple Developer 签名后 Archive。
- `curl | bash` 用户：重新运行安装脚本即可切到新版本。
- Homebrew 用户：`brew update && brew upgrade honeclaw`。

## 已知注意事项

- macOS DMG 仍为 ad-hoc 签名且未公证；没有配置 Apple Developer 签名时，iOS Release 仍只提供 Simulator App 与 Xcode 工程，不提供真机 IPA。
- Tag 推送会触发远端多平台与 Apple 构建；只有 Release workflow 全部完成并通过校验后，资产才视为正式可用。

## English

Release date: 2026-07-27

### What Users Should Know

- This is a production rollout and Apple-package refresh. It does not add features or change the established answer format, interaction flow, or business behavior.
- Production will move from the old `0.14.1` runtime to the current security baseline, including the public-site security headers, SMS anti-enumeration and server-side limits, archive-extraction resource bounds, chart-rendering limits, credential-file permissions, and dependency security fixes already published in `v0.15.1`.
- The Universal macOS DMG, iOS Simulator App, and iOS Xcode project will be rebuilt from current `main` and consistently marked `0.15.2`.
- Since `v0.15.1`, only bug-ledger evidence changed; there is no new runtime code or architecture change.

### Who Should Update Soon

- Operators still running a `0.14.x` backend who have not deployed the `v0.15.1` security fixes.
- Users who need macOS/iOS artifacts that exactly match the current production deployment and GitHub tag.

### What Will Change After Upgrading

- The backend will be replaced through the established supervisor only after active chats reach zero, while PostgreSQL/R2 remains the sole authoritative storage.
- Public Web, Feishu, authentication boundaries, conversation history, and Apple client formats remain compatible.
- This release does not change module boundaries, primary routes, Agent runners, tools, channels, or storage layout, so `resources/architecture.svg` does not require an update.

### Install and Update

- macOS user app: download `HONE-macOS-v0.15.2-universal.dmg` from the GitHub Release.
- iOS development/verification: download `HONE-iOS-Simulator-v0.15.2.zip` or `HONE-iOS-Xcode-v0.15.2.zip`; configure Apple Developer signing in Xcode before creating a device archive.
- `curl | bash` users: rerun the installation script to move to this version.
- Homebrew users: `brew update && brew upgrade honeclaw`.

### Known Notes

- The macOS DMG remains ad-hoc signed and is not notarized. Without configured Apple Developer credentials, the iOS release contains a Simulator App and Xcode project rather than a device IPA.
- Pushing the tag starts the remote multi-platform and Apple builds. Assets are final only after the full Release workflow and checksum verification succeed.
