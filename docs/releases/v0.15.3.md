# v0.15.3

发布日期：2026-07-27

English readers: please scroll down for the English version below.

## 用户应该知道的

- 修复飞书消息把表格组件源码直接显示给用户的问题。标准 Markdown 表格现在会转换成飞书卡片 JSON 2.0 原生表格，而不是作为 `<table columns=...>` 文本出现在正文中。
- 兼容此前已经生成的完整 raw table 数据；无法解析、超过协议边界或只能使用 Markdown 的路径会降级为可读列表或明确提示，不再暴露内部组件代码。
- Feishu direct、scheduler 和 placeholder 最终更新共用同一套表格渲染逻辑。

## 谁应该尽快更新

- 使用 Feishu 接收投研报告、评级表、财报日历或其它包含 Markdown 表格内容的部署。
- 曾在飞书消息中看到 `<table columns=...>`、`dataIndex` 或 `col0` 等内部字段的用户和维护者。

## 升级后会有什么变化

- 标准 Markdown 表格在飞书最终消息中显示为可横向浏览、分页的原生表格组件。
- 单张卡片遵守最多 5 个表格、单表最多 50 列的飞书协议边界；超限或损坏内容不会回退成组件源码。
- 普通文本、图片顺序、会话行为和其它渠道不受影响。
- 本次没有新增或删除 channel binary、route、Agent runner、工具、crate 或存储布局，因此 `resources/architecture.svg` 无需更新。

## 安装与更新

- `curl | bash` 用户：重新运行安装脚本即可切到新版本。
- Homebrew 用户：`brew update && brew upgrade honeclaw`。
- macOS/iOS 用户：等待 GitHub Release workflow 完成后，从 `v0.15.3` Release 下载对应构建产物。

## 已知注意事项

- 本次正式发布不包含生产环境部署或运行时重启；现有线上实例需要按正常部署流程加载 `v0.15.3` 后，修复才会生效。
- macOS DMG 仍为 ad-hoc 签名且未公证；没有配置 Apple Developer 签名时，iOS Release 仍只提供 Simulator App 与 Xcode 工程。

## English

Release date: 2026-07-27

### What Users Should Know

- Fixes Feishu messages displaying internal table-component source. Standard Markdown tables are now converted into native Feishu Card JSON 2.0 tables instead of appearing as `<table columns=...>` text.
- Complete legacy raw-table data remains compatible. Unparseable, protocol-limit, or Markdown-only paths fall back to readable lists or a clear notice without exposing internal component code.
- Feishu direct messages, scheduled delivery, and final placeholder updates now share the same table renderer.

### Who Should Update Soon

- Deployments that use Feishu for research reports, ratings tables, earnings calendars, or other Markdown-table content.
- Users and operators who have seen internal fields such as `<table columns=...>`, `dataIndex`, or `col0` in Feishu messages.

### What Will Change After Upgrading

- Standard Markdown tables render as native, horizontally scrollable and paginated tables in final Feishu cards.
- Each card follows Feishu's limit of five tables and 50 columns per table; malformed or over-limit content never falls back to component source.
- Plain text, image ordering, conversation behavior, and other channels remain unchanged.
- This release adds or removes no channel binary, route, Agent runner, tool, crate, or storage layout, so `resources/architecture.svg` does not require an update.

### Install and Update

- `curl | bash` users: rerun the installation script to move to this version.
- Homebrew users: `brew update && brew upgrade honeclaw`.
- macOS/iOS users: wait for the GitHub Release workflow to finish, then download the matching artifacts from the `v0.15.3` Release.

### Known Notes

- This formal release does not include a production deployment or runtime restart. Existing production instances must load `v0.15.3` through the normal deployment workflow before the fix takes effect.
- The macOS DMG remains ad-hoc signed and is not notarized. Without configured Apple Developer credentials, the iOS release contains a Simulator App and Xcode project rather than a device IPA.
