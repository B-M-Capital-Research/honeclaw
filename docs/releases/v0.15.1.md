# v0.15.1

发布日期：2026-07-27

English readers: please scroll down for the English version below.

## 用户应该知道的

- 公共站点现在统一发送 HSTS、禁止 iframe 嵌入、禁止 MIME 嗅探并收紧 Referrer Policy，降低点击劫持和降级传输风险。
- 短信登录不再通过状态、响应正文或短信服务商耗时泄露手机号是否受邀；服务端新增有界的手机号/IP 发送频率、成功重发冷却和限流器容量上限。
- ZIP 与 TAR 系列附件解压现在同时限制文件数、单文件大小、累计解压字节、压缩膨胀比和单用户沙箱占用，拒绝时会清理不完整输出。
- 图表技能现在限制参数数量、序列/数据点规模、直方图分桶和输入字节，并为渲染子进程设置超时与退出清理。
- 配置文件写入使用原子、仅所有者可读写的 `0600` 权限；管理员令牌修改会要求完整重启；Discord 令牌输入不再回显。
- 云端 Web 邀请记录不再持久化一次性 API Key 明文，启动时会清理历史记录中的旧明文字段，仅保留校验摘要和非敏感前缀。
- QUIC、Serde、Tauri 与 Telegram 依赖已升级到当前兼容安全版本，关闭远程内存耗尽和恶意序列化崩溃等已知依赖告警。

## 谁应该尽快更新

- 将 `hone-claw.com` 或自建公共 Web 入口暴露到互联网的维护者。
- 启用了短信登录、附件上传/解压、图表技能或云端邀请 API Key 的部署。
- 使用共享主机、多人账户或自动化配置管理，要求本机凭据权限和管理员令牌轮换立即生效的用户。

## 升级与运维注意事项

- `web.auth_token` 变更现在返回完整重启要求；请通过既有进程 supervisor 受控重启，不要从临时 shell 启动第二个服务。
- 云端 schema 初始化会幂等删除历史 `api_key_plaintext` 字段，不改变已存摘要、用户身份或现有会话。
- 短信接口仍需配置服务商凭据；浏览器倒计时、服务商配额、验证码和 WAF 只能作为应用内服务端限流之外的附加保护。
- 本版本没有改变模块边界、主要路由拓扑或存储权威关系，因此 `resources/architecture.svg` 无需更新。
- 远端 release workflow 会在 tag 推送后构建多平台与 Apple 产物；tag 创建不代表所有资产已经完成上传。

## 安装与更新

- macOS 用户端：从 GitHub Release 下载 `HONE-macOS-v0.15.1-universal.dmg`。
- iOS 开发/验证：下载 `HONE-iOS-Simulator-v0.15.1.zip` 或 `HONE-iOS-Xcode-v0.15.1.zip`；真机分发仍需在 Xcode 中配置 Apple Developer 签名后 Archive。
- `curl | bash` 用户：重新运行安装脚本即可切到新版本。
- Homebrew 用户：`brew update && brew upgrade honeclaw`。

## English

Release date: 2026-07-27

### What Users Should Know

- The public site now sends HSTS, denies iframe embedding, disables MIME sniffing, and uses a stricter referrer policy, reducing clickjacking and transport-downgrade exposure.
- SMS login no longer reveals invite membership through status, response bodies, or provider latency. Server-side phone/IP budgets, successful-resend cooldowns, and a bounded limiter keyspace are enforced.
- ZIP and TAR-family extraction now enforces file-count, per-file, cumulative-byte, expansion-ratio, and per-actor sandbox limits, with partial output removed on rejection.
- The chart skill now bounds argument count, series/data-point volume, histogram bins, and input bytes, and terminates renderer children on timeout or cancellation.
- Configuration writes are atomic and owner-only (`0600`); administrator-token changes require a full restart; Discord token entry is hidden.
- Cloud Web invite records no longer persist one-time API-key plaintext. Schema initialization removes the legacy field while retaining the digest and non-secret prefix.
- QUIC, Serde, Tauri, and Telegram dependencies are updated to current compatible security releases, closing known remote-memory-exhaustion and malicious-serialization crash advisories.

### Who Should Update Soon

- Operators exposing `hone-claw.com` or another public Web entrypoint to the Internet.
- Deployments using SMS login, attachment extraction, chart rendering, or cloud invite API keys.
- Shared-host or automated deployments that rely on strict local credential permissions and immediate administrator-token rotation.

### Upgrade and Operations Notes

- Changing `web.auth_token` now requires a full restart. Use the established process supervisor; do not start an ad-hoc second service.
- Cloud schema initialization idempotently removes legacy `api_key_plaintext` fields without changing stored digests, identities, or sessions.
- SMS-provider credentials remain required. Browser cooldowns, provider quotas, captcha, and WAF rules are defense-in-depth and do not replace the application limits.
- This patch does not change module boundaries, primary route topology, or storage authority, so `resources/architecture.svg` did not require an update.
- The remote release workflow builds multi-platform and Apple artifacts after the tag is pushed; tag creation does not mean every asset has finished uploading.

### Install and Update

- macOS user app: download `HONE-macOS-v0.15.1-universal.dmg` from the GitHub Release.
- iOS development/verification: download `HONE-iOS-Simulator-v0.15.1.zip` or `HONE-iOS-Xcode-v0.15.1.zip`; configure Apple Developer signing in Xcode before creating a device archive.
- `curl | bash` users: rerun the install script to update.
- Homebrew users: `brew update && brew upgrade honeclaw`.
