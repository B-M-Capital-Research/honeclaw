# v0.15.0

发布日期：2026-07-26

English readers: please scroll down for the English version below.

## 用户应该知道的

- HONE 现在会在会话历史接近或超过模型上下文上限时自动压缩并继续回答，不再把“当前会话上下文过长”、`/compact` 或“开启新会话”等内部恢复指引暴露给普通用户。
- 普通问答和财经研究不再落入固定拒答、笼统失败或“研究未完成”的占位结论。原有 prompt 约定的回答首行与正文格式保持不变；当外部资料受限时，同一个 Agent 会基于已经核验的证据给出可用结论，并清楚说明缺口。
- “美股为什么大跌”及指定交易日的市场归因会保留用户要求的日期和范围，核验至少两组代表性宽基行情，区分实时价、收盘价、涨跌幅和交易所字段，并避免把搜索摘要或未经证实的传言当成确定原因。
- 单股、跨市场 ticker、盘前盘后价格和估值问题的实体解析与证据约束进一步加强，减少答错标的、引用错价格、把反向 ETF 方向说反以及把任务配置词误识别成股票代码的情况。
- Web 与 Apple 用户端采用新的三项核心导航和更聚焦的对话 Agent；“我的”集中持仓与设置，聊天记录按日期分组，投资页提供行情快照，移动端抽屉、输入区和页面切换也更稳定。
- 云端权威模式不再把会话和生成物写入本地磁盘，云端存储边界与用户隔离更加明确。

## 谁应该尽快更新

- 遇到财经问题拒答、回答到一半失败、长会话要求手工压缩，或“美股为什么大跌”缺少有效结论的用户。
- 使用 HONE Web、macOS App 或 iOS Simulator/Xcode 客户端，并希望获得新导航、投资工作台和聊天历史体验的用户。
- 在云端权威模式运行 HONE，要求会话、附件与生成物严格留在云端存储边界内的维护者。
- 使用 scheduler、Feishu 或多市场 ticker 研究链路的维护者。

## 升级后会有什么变化

- 上下文恢复改为服务端自动完成。正常情况下用户只会看到最终回答，不需要知道压缩、重试或内部工具过程。
- 财经回答继续遵守既有 prompt 的时间首行、标题和正文格式；本版本改变的是证据校验、失败恢复和终止逻辑，不会擅自改写产品约定的回答排版。
- 公共用户端主导航收敛为首页/Agent、社区和“我的”核心入口；原有账号、历史会话、持仓、推送偏好和已读状态不会被迁移或清空。
- macOS 与 iOS 客户端仍是连接 `hone-claw.com` 的远程用户端，不包含服务端数据库、Feishu 监听、Codex ACP 或本地投资数据副本。

## 安装与更新

- macOS 用户端：从 GitHub Release 下载 `HONE-macOS-v0.15.0-universal.dmg`。
- iOS 开发/验证：下载 `HONE-iOS-Simulator-v0.15.0.zip` 或 `HONE-iOS-Xcode-v0.15.0.zip`；真机分发需在 Xcode 中配置 Apple Developer 签名后 Archive。
- `curl | bash` 用户：重新运行安装脚本即可切到新版本。
- Homebrew 用户：`brew update && brew upgrade honeclaw`。

## 已知注意事项

- 仓库尚未配置 Apple Developer ID、notarization、iOS Distribution 证书和 provisioning profile。macOS DMG 为 ad-hoc 签名，另一台 Mac 仍可能显示 Gatekeeper 提示；iOS Release 提供 Simulator App 与 Xcode 源码包，不会误标为可安装到真机的 IPA。
- Apple 用户端依赖 `hone-claw.com` 网络可用性，不支持离线对话。
- Public Community 的私有 R2 Edge 交付仍受分阶段开关保护；未显式启用的路径保持 fail-closed，不影响现有社区读取链路。
- 本版本已同步刷新架构 SVG：Codex ACP / GPT-5.6 默认执行链路、公共用户端路由、workspace crate 数和 `v0.15.0` 里程碑均已对齐当前代码。
- 远端 release workflow 在 tag 推送后生成多平台与 Apple 产物；tag 创建本身不代表所有资产已经完成上传。

## English

Release date: 2026-07-26

### What Users Should Know

- HONE now compresses conversation history and continues automatically when a session approaches or exceeds a model context limit. Ordinary users no longer see internal recovery guidance such as “context too long,” `/compact`, or “start a new session.”
- General questions and financial research no longer fall through to canned refusals, generic failures, or placeholder “research incomplete” conclusions. The first-line and body format defined by the existing prompt remains unchanged. When external evidence is limited, the same Agent produces the best usable conclusion from verified evidence and states any remaining gap.
- Broad-market questions such as “Why did U.S. stocks fall?” preserve the requested date and scope, verify at least two representative market groups, distinguish live price, close, percentage-change, and exchange fields, and avoid presenting search snippets or unverified rumors as settled causes.
- Entity resolution and evidence checks are stronger for single stocks, cross-market tickers, extended-hours quotes, and valuation questions. This reduces wrong-security answers, mismatched prices, reversed leveraged-ETF direction, and scheduler configuration words being mistaken for symbols.
- The Web and Apple user experience now uses a focused three-destination navigation and a conversation-first Agent. “Me” combines portfolio and settings, history is grouped by date, the investment page includes market snapshots, and mobile drawers, composers, and transitions are more stable.
- Cloud-authoritative mode no longer writes sessions or generated artifacts to local disk, making the cloud storage and user-isolation boundary explicit.

### Who Should Update Soon

- Users who have encountered refusals, mid-answer failures, manual context-compaction instructions, or unusable results for broad-market questions.
- HONE Web, macOS, or iOS Simulator/Xcode users who want the new navigation, investment workspace, and history experience.
- Operators who require sessions, attachments, and generated artifacts to remain within the cloud-authoritative storage boundary.
- Maintainers using scheduler, Feishu, or multi-market ticker research paths.

### What Will Change After Upgrading

- Context recovery is now handled automatically by the service. Under normal operation, users see only the final answer and do not need to know about compaction, retries, or internal tools.
- Financial answers continue to follow the existing prompt-defined time header, headings, and body format. This release changes evidence validation, failure recovery, and termination behavior without rewriting the product's answer layout.
- The public user experience centers on Home/Agent, Community, and Me. Existing accounts, conversation history, portfolios, push preferences, and read state are not migrated or cleared.
- The macOS and iOS clients remain remote clients for `hone-claw.com`; they bundle no server database, Feishu listener, Codex ACP runtime, or local investment-data copy.

### Install and Update

- macOS user app: download `HONE-macOS-v0.15.0-universal.dmg` from the GitHub Release.
- iOS development/verification: download `HONE-iOS-Simulator-v0.15.0.zip` or `HONE-iOS-Xcode-v0.15.0.zip`; configure Apple Developer signing in Xcode before creating a device archive.
- `curl | bash` users: rerun the install script to move to this version.
- Homebrew users: `brew update && brew upgrade honeclaw`.

### Known Notes

- Apple Developer ID, notarization, iOS Distribution certificates, and provisioning profiles are not configured. The macOS DMG is ad-hoc signed and may trigger Gatekeeper on another Mac. The iOS Release contains a Simulator app and Xcode source archive and is not mislabeled as a device-installable IPA.
- Apple clients require network access to `hone-claw.com` and do not provide offline chat.
- Private-R2 delivery for Public Community remains protected by staged rollout gates. Routes that have not been explicitly enabled stay fail-closed without changing the existing community read path.
- The architecture SVG is refreshed in this release to reflect the Codex ACP / GPT-5.6 default execution path, current public routes, workspace crate count, and the `v0.15.0` milestone.
- The remote Release workflow builds multi-platform and Apple assets after the tag is pushed; creating the tag alone does not mean every asset has finished uploading.
