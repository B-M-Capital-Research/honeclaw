## Risks / Follow-ups

- Keep `target/deploy-620391d1` as the immediate rollback package. If a production regression appears, drain active chats, stop the `deploy-8491a3c2` supervisors with SIGINT, restart the prior exact commands against `deploy-620391d1`, and repeat the cloud/storage/channel/auth probes.
- The macOS DMG is ad-hoc signed and not notarized because no Developer ID/notarization credentials are configured; Gatekeeper may warn on another Mac.
- The iOS deliverables are a Simulator App and Xcode source project, not a device-installable IPA or App Store archive. Apple Developer signing and provisioning remain prerequisites for device distribution.
- Discord was already stopped before this rollout because the configured gateway credential is rejected. Web and Feishu are healthy; do not attribute the unchanged Discord state to `v0.15.2`.
- GitHub emitted a non-blocking warning that `mozilla-actions/sccache-action@v0.0.9` targets Node.js 20 while the runner forces Node.js 24. The release succeeded; update the action during normal workflow maintenance.
