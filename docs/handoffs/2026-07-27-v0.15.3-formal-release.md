## Summary

Published HONE `v0.15.3` as a focused patch for Feishu native-table rendering. The release commit and annotated tag point to `9b75868fb202da58ef0559d57834510f0af7a694`; the non-draft, non-prerelease GitHub Release is available at `https://github.com/B-M-Capital-Research/honeclaw/releases/tag/v0.15.3`.

The source workspace had an unrelated unfinished merge and conflict. The release was therefore built from a fresh clone of the latest `origin/main`, with only the verified table fix and its documentation migrated by exact patch; unrelated user changes were not resolved, staged, committed, or discarded.

## What Changed

- Updated all 21 Rust workspace package versions, both Tauri clients, and the iOS marketing version to `0.15.3`.
- Added bilingual `docs/releases/v0.15.3.md`; architecture SVG was intentionally unchanged because no topology changed.
- Published standard Markdown and legacy raw-table conversion to root-level Feishu JSON 2.0 tables, shared by direct, scheduler, and placeholder final updates.
