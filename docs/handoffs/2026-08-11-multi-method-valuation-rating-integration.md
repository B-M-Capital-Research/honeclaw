# 多方法每日估值与公司评级联动交接

## 完成结果

每日估值实验室已从通用的 DCF/P-E 混合模型升级为 `hone-valuation-v2`。模型按商业模式路由：周期制造采用前瞻 P/E、EV/EBIT、周期调整 DCF；盈利成长采用前瞻 P/E、EV/EBIT、DCF；收入转型采用 EV/S 为主并要求第二方法验证。三情景使用 20%/55%/25% 概率，界面展示方法级结果、权重、概率加权价值、预期空间和反向估值。

每日公司评级已升级为 `hone-company-rating-v4`。只有同日、至少两种方法、high/medium confidence、日期和报价一致的 `hone-valuation-v2 / computed` 结果能够进入 15% 估值分；旧结果被拒绝。估值分以概率加权空间为主，并按置信度和方法覆盖收缩。缺失估值时继续移除该权重，不填中性分。

演讲研究材料中的 1–5 档结构判断改用 25/45/60/75/90 锚点，不再机械乘 20。90 表示现有材料中的最高证据档，不代表“完美公司”；动态基本面最高 95。公司评级弹窗增加评分公式、锚点解释、当日估值覆盖数和每家公司“含当日估值 / 暂未含估值 / 研究基线分”标签。

## 调度与文件

- 19:20 Asia/Shanghai：估值实验室刷新，写 `data/valuation_lab/daily.json`。
- 同一任务：把合格行写到 `data/company_ratings/valuations/latest.json`，随后立即刷新公司评级。
- 19:30 Asia/Shanghai：公司评级独立刷新兜底，写 `data/company_ratings/daily.json`。
- API：`GET /api/public/valuation-lab` 与现有公司评级 API 均为只读快照。

## 数据门禁

- 行情不超过四天，财务数据不超过 200 天。
- 下一财年一致预期会跳过距离结束不足 180 天的财年。
- 每个情景至少两种可复算方法，三情景必须为有序正值。
- 基准方法离散度不超过 50%；否则保留在实验室供复核但不进入评级。
- 周期类才从净现金中扣除合同负债，并以最多五个年度窗口的正 FCFF 中位数作为周期回归锚。

## 验证与当前环境

- Web API：276 passed / 2 ignored；含周期制造与盈利成长回归。
- 前端相关测试：22/22；TypeScript、public build、Rust format、console build、diff check 通过。
- 当前本地配置没有 FMP key pool，所以新快照正确显示 52 家 `data_unavailable`、0 家进入公司评级。页面会直接说明本次没有取得行情与财务输入；这证明失败关闭有效，不代表联动代码缺失，也不能把旧目标价冒充为当日估值。
