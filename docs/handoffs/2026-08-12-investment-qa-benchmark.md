## Summary

已在同一北京时间截面完成五题 HONE 实测，并用隔离环境中的 GPT-5.6 Sol 生成独立参考答案。HONE 本轮总分 **149 / 500，平均 29.8 / 100，0 / 5 题通过**，未达到上线门槛。核心问题不是措辞不够大胆，而是实时事实没有稳定进入最终答案，且要求的 `hari-invest` 与 `company-thesis-ratings` 均没有成功加载证据。

GPT-5.6 Sol 的参考答案在一手来源、日期、数字覆盖和行动结论方面显著更完整，但它不是裁判答案；个别二手来源和未来财务数字仍需复核。最终准确性必须按公司 IR、SEC、监管机构和交易所等一手来源判断，不能按两份答案的一致程度判断。

答案里写“按老王框架”不等于使用了 Skill。本基准只认可运行时审计中成功的 Skill 调用，或能够证明等价原生加载的记录。

### 根因定位

1. GPT Luna 的 OpenAI-compatible 流式工具调用仍存在参数归属问题：工具名和调用 ID 已能分开，但后续仅含 arguments、缺少 index / id 的增量会被拼到前一个工具，形成多个 JSON 对象串联的非法参数。
2. 安全执行器因此把该批 `data_fetch`、`web_search`、`skill_tool` 判为不安全并阻断；最终答案退化为“无工具”回答。
3. 本地没有 FMP 数据源，进一步削弱了行情与标准财务字段覆盖；Tavily 可用，但同一批工具调用异常使搜索结果无法稳定进入答案。
4. Prompt 中要求优先加载 Skill 只是意图约束，并不能保证运行时成功；必须把成功调用和版本写进可观测审计。

## Risks / Follow-ups

- 第一优先级：修复无 index / id 的流式 arguments 归属，并增加“多工具、参数分片、顺序交错”的回归测试。
- 第二优先级：在本地接入可靠行情 / 财务源，或在缺少 FMP 时明确走可核验的一手来源降级链路。
- 第三优先级：为投资问题增加强制 Skill 执行门禁；所需 Skill 未加载时应重试或明确失败，不应伪装成已使用框架。
- 修复后必须原题重跑，达到单题 75、平均 80、零硬失败再考虑上线。
- 参考答案本身含少量二手资料；复核重大数字时仍以一手来源为准。
