## Risks / Follow-ups

- `HONE-macOS-v0.15.0-universal.dmg` is ad-hoc signed and not notarized because no Developer ID/notarization credentials are configured. Gatekeeper may warn on another Mac.
- `HONE-iOS-Simulator-v0.15.0.zip` is a Simulator build. `HONE-iOS-Xcode-v0.15.0.zip` is the source project for signed development builds. This release does not contain a device-installable IPA or App Store archive because no Apple Developer signing identity/provisioning profile is configured.
- GitHub emitted a non-blocking warning that `mozilla-actions/sccache-action@v0.0.9` still targets Node.js 20 while the runner forces Node.js 24. The release succeeded, but the action should be upgraded during normal workflow maintenance.
