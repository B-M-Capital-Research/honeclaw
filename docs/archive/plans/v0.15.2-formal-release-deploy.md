## Goal

Synchronize the latest remote `main`, publish it as `v0.15.2`, replace the old production `0.14.1` runtime with an exact immutable `0.15.2` build through the established supervisor, and publish newly verified macOS and iOS release assets.

## Scope

- Preserve all current answer-format, interaction, cloud-authority, and channel contracts.
- Carry the already released but not yet deployed `v0.15.1` security baseline into production.
- Synchronize workspace, Tauri, and Xcode versions to `0.15.2`.
- Build a new immutable runtime directory and retain `target/deploy-620391d1` as the immediate rollback package.
- Require two zero-active-chat checks before replacement, then verify process paths, ports, cloud authority, authentication boundaries, public assets, history, and Feishu.
- Build and locally verify the Universal macOS App. Require the tag-triggered Apple job for the iOS Simulator/Xcode artifacts because this host exposes Command Line Tools rather than full Xcode.
- Push the release commit to `main`, create and push annotated tag `v0.15.2`, monitor the GitHub Release, and verify all published checksums.
