# HONE 投资内核清单

## 版本身份

- 产品：Hari Invest
- Skill ID：`hari-invest`
- HONE 默认投资内核版本：`0.3.0`
- 集成日期：2026-08-29
- 目标分支：`oldwang`
- 运行范围：美国市场上市公司、ETF 和 ADR 的研究问答；非投资问题不触发

## 来源分层

| 层级 | 状态 | 进入默认判断的方式 | 内容 |
|---|---|---|---|
| A | `confirmed_l4` | 强规则 | `LOG-V0001`—`LOG-V0006`，版本均为 0.1 |
| B | `method_transfer` | 分析结构 | SNDK 深度因果链、财务桥、三情景与反向估值 |
| C | `historical_baseline` | 命中公司时辅助 | `company-thesis-ratings` 的商业模式、护城河、风险和证伪基线 |
| D | `current_evidence` | 本轮重新核实 | 行情、SEC/IR、财报、订单、新闻、产业数据、持仓和估值输入 |
| E | `candidate_or_open` | 只展示未知，不作固定规则 | 完整决策闭环、拥挤度冲突优先级、长期训练与自主执行范围 |

优先级不是“旧框架压过新事实”。当前一手证据可以证明历史逻辑加强、削弱或失效；系统必须说明变化，不能静默沿用旧结论。

## 默认调用顺序

1. 确认证券实体、上市状态、问题类型和数据时间。
2. 读取 HONE 统一点时决策状态；缺失或校验失败时不沿用旧动作。
3. 加载 `hari-invest`；命中历史公司卡时同时加载 `company-thesis-ratings`。
4. 用当前行情、SEC/IR、财报、公司公告、新闻和组合工具核实会改变结论的事实。
5. 深度个股按需求、供给/替代、价值捕获、财务兑现、情景估值、反向隐含要求和条件化动作形成闭环。
6. 用六条 L4 逻辑检查首次机会、稀缺差异化、市场/组合风险、杠铃、板块预算和回调后的剩余空间。
7. 输出一个研究区间、置信度、短中长期差异、最强反方和 2—4 个改变判断的条件。

## SNDK 迁移边界

可迁移：

- 从终端需求到公司收入和现金流的可审计传导链；
- 量、价、结构、利润率、营运资本、资本开支与自由现金流的财务桥；
- 护城河、稀缺性、差异化、份额和周期位置分开论证；
- 悲观/基准/乐观情景、第二方法交叉和当前价格反向隐含要求；
- 对领先指标不等于现金/利润、未认证新业务不进入基准情景的证据纪律。

不可迁移：

- 某一时点 SNDK 的价格、财务数字、预测、目标价、评级和动作；
- NAND/HBF 专项变量到所有行业的机械套用；
- 未经一手证据确认的良率排名、客户关系、份额、订单或供给结论。

## 代码强制点

- `crates/hone-channels/src/prompt.rs`：投资问题强制加载 Hari；命中公司卡时双 Skill；深度个股使用通用传导链。
- `crates/hone-channels/src/turn_builder.rs`：为投资轮建立必需 Skill 集合。
- `crates/hone-channels/src/investment_response_guard.rs`：检查数据时间、证据、估值和 SNDK 专项深度契约。
- `crates/hone-core/src/investment_decision_context.rs`：向对话提供统一、版本化的点时决策状态。
- `skills/company-thesis-ratings/`：只提供历史公司基线，不替代当前事实。
