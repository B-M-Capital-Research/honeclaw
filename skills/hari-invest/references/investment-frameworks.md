# 投资框架

版本：0.3.0（本地 HONE 默认投资内核）

## 1. 首次买入：第一性原理与现实验证

1. 把需求、供给、技术及其关系压缩成可解释公式。
2. 判断公式是否支持长期产业趋势。
3. 用价格、供需缺口、技术进展、产能、订单及业绩兑现验证。
4. 公式未想清楚或现实证据不足时，只保留为研究线索。

## 2. 公司选择：稀缺与差异化

稀缺性回答“需求相对供给是否紧张”；差异化回答“为什么价值由这家公司获得”。

- 稀缺性：比较需求增长与供给扩张，观察价格、订单、积压订单和产能约束。
- 差异化：检查不可替代性、少数供应商、客户验证、市场份额、技术或品牌壁垒、认证周期、切换成本和数据壁垒。
- 财务支持：订单、收入、现金流和毛利是现实兑现证据；毛利增强是强支持信号，但不是所有行业的必要条件。
- 能力必须被证明。路线图、潜在能力和赛道热门不能替代良率、交付、客户采用和财务兑现。

## 3. 市场状态：牛熊与总仓位

- 总验证：原先支持买入和上涨的理由是否仍成立。
- 宏观层：流动性、长期利率、通胀及其变化。
- 衰退层：就业、失业和硬着陆风险。
- 产业层：投入、供需、价格和产业下行风险。
- 单一价格下跌或单一板块恶化，不能自动定义全市场熊市。

## 4. 组合结构：动态杠铃

一端为商业质量可靠、相对抗跌且流动性较好的压舱石；另一端为有现实业绩驱动的高成长 Beta。

- 市场和产业条件有利时，可以提高高成长端暴露。
- 宏观转弱或高成长端缺少兑现时，降低高 Beta，保留稳定性和流动性。
- 压舱石身份不是永久的；其现金流、需求和商业质量恶化时必须重新验证。
- 本版本不提供两端固定比例或固定证券清单。

## 5. 仓位分配：板块优先

1. 先根据板块稀缺性、差异化、持续性和业绩兑现确定板块预算。
2. 再根据公司不可替代程度、现金流、毛利和财务质量在板块内分配。
3. 检查同板块公司的客户、收入和风险暴露相关性，避免把高度相关标的误当作充分分散。
4. 板块强不能覆盖公司层面的差异化未证明或财务恶化。

## 6. 回调后的去留：未来剩余空间

重新比较：`未来需求空间` 与 `未来供给释放 + 替代能力`。

- 未来空间仍大、稀缺和差异化未破坏、回调来自短期分歧时，可把回调视为增加暴露的候选机会。
- 未来空间缩小、竞争增强、替代出现，或订单、价格、毛利、现金流持续恶化时，应收缩暴露或离场。
- “低点”“增加暴露”和“离场”均需结合用户组合与约束，本框架不输出固定交易指令。

## 7. 深度个股传导链（产品方法，不是新增确认逻辑）

这套结构由 SNDK 深度分析重构提炼为通用个股方法，用来确保基本面、护城河和估值不是彼此割裂的栏目。它不得覆盖 `LOG-V0001`—`LOG-V0006`，也不得把某次 SNDK 研究数字迁移到其他公司。

1. **需求**：明确最终客户、使用场景、计量单位、增长函数与持续期；把“AI 很好”改写成可验证需求变量。
2. **供给与替代**：检查有效产能、良率、认证、扩产时滞、竞争者策略、替代路线与价格弹性。
3. **公司价值捕获**：回答为什么需求会落到这家公司，拆开稀缺、差异化、客户切换成本、议价权和份额质量。
4. **财务兑现**：把量、价、产品结构传到收入、毛利、费用、营运资本、资本开支、自由现金流和资产负债表；积压订单、ARR、RPO 或 NBM 只作领先线索，不能直接当现金或利润。
5. **情景估值**：悲观、基准、乐观情景必须披露关键经营输入、正常化利润或现金流、持续期和适用倍数；至少用第二种适用方法交叉检查。
6. **反向隐含要求**：从当前价格倒推市场要求的增长、利润率、现金流或持续期，判断当前赔率，而不是只给一个目标价。
7. **条件化动作**：落到机会区、持有区、风险区或数据不足，给出升级、降级和证伪条件。

SNDK 专项边界仍由代码级回答契约约束：NAND 量价拆分，良率/控制器与固件/客户认证/切换成本/供给约束分开论证；HBF 未经认证和规模放量不得进入基准情景。这些专项边界不能无条件套到不相关行业。
