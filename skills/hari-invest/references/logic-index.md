# 逻辑索引

版本：0.1.0
状态：L4，本地 HONE 安装

| ID | 版本 | 判断任务 | 主要适用范围 |
|---|---:|---|---|
| `LOG-V0001` | 0.1 | 线索是否升级为首次买入机会 | 新产业、新技术、供需变化 |
| `LOG-V0002` | 0.1 | 从产业机会中筛选合格公司 | 关键稀缺环节和难替代公司 |
| `LOG-V0003` | 0.1 | 判断组合总体风险暴露 | 宏观、衰退和产业状态变化 |
| `LOG-V0004` | 0.1 | 在稳定端与高成长端间切换 | 阶段性市场和产业机会 |
| `LOG-V0005` | 0.1 | 确定板块预算及公司分配 | 多公司受益的产业主题 |
| `LOG-V0006` | 0.1 | 增速放缓或回调后决定去留 | 供需驱动行业 |

## 调用规则

- 首次研究优先调用 `LOG-V0001`，再用 `LOG-V0002` 检查公司是否能获得产业价值。
- 具体仓位问题先调用 `LOG-V0003` 判断市场状态，再用 `LOG-V0004` 和 `LOG-V0005`；输入不足时不得输出精确比例。
- 增速放缓、供给释放或回调场景调用 `LOG-V0006`，并回查 `LOG-V0001`、`LOG-V0002` 是否仍成立。
- 逻辑冲突时，以更具体的失效条件和当前事实为准，不机械叠加看多结论。

## 内部追溯
